# Fastest Slideshow

Tiny native Mac image viewer (one Swift file, about 120 KB zipped, half of it the icon). Apple Silicon, macOS 13+.

Opens a folder or image full screen on the first image, paused.

## Keys

| Key | Action |
| --- | --- |
| Right / `j` | Next image |
| Left / `k` | Previous image |
| Control or Shift + Left / Right / `j` / `k` | Skip 10 images (flashes `+10` / `-10`) |
| `f` / Enter | Toggle full screen |
| `i` | Toggle metadata sidebar |
| Space | Play / pause (3 seconds per image) |
| Escape | Close the image (app keeps running) |
| Cmd-O / Cmd-Q | Open / quit |

Control + arrows are macOS Mission Control shortcuts by default. If they switch
Spaces instead of skipping, use Shift + arrows, or turn those shortcuts off in
System Settings > Keyboard > Keyboard Shortcuts > Mission Control.

## Opening from Finder

- Folder: right-click > Services (or Quick Actions) > Open in Fastest Slideshow.
  Finder has no "Open With" for folders, so the app registers this service.
  It appears after the app is in /Applications and has been launched once. If
  it is missing, enable it in System Settings > Keyboard > Keyboard Shortcuts >
  Services > Files and Folders, where it can also be given a keyboard shortcut.
- Image: right-click > Open With > Fastest Slideshow (the service works too).
- Drag a folder or images onto the app icon in the Dock.
- Shortcuts app: new shortcut > "Open File" action > Open "Shortcut Input" with
  Fastest Slideshow > enable "Use as Quick Action" > Finder. It then appears
  under right-click > Quick Actions, and can be given a keyboard shortcut.
- Terminal: `open -a "Fastest Slideshow" /path/to/folder`

Opening one image shows that image and lets you browse the rest of its folder.
Opening a folder shows the images directly inside it (no subfolders).

## Build

```bash
./build.sh            # ad-hoc signed, for this Mac
./build.sh --release  # Developer ID signed + notarized, for other Macs
```

Output: `builds/FastestSlideshow-<version>.zip`. The version lives in `Info.plist`
(bump `CFBundleShortVersionString` and `CFBundleVersion` per release) and shows
in the About panel and at the bottom of the metadata sidebar.

```bash
./publish.sh          # upload current version to the fixed download URL
```

Download URL never changes: https://echeng.com/f/FastestSlideshow.zip

The icon is generated by `make_icon.swift` (see its first line to regenerate).

Headless self-check:

```bash
B="build/Fastest Slideshow.app/Contents/MacOS/FastestSlideshow"
"$B" --check /path/to/image-or-folder
```
